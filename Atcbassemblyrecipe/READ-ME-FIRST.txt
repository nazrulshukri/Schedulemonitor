THE WIREBOND GRID IS NOW THE MACHINE LIST
=========================================
Add a wire bonder in AWACSWSTYPE (WSTYPE WIREBOND) and it appears on the
Wirebond page straight away - as an empty row at the top of the grid,
with its machine already filled in and PACKAGE / Product / Leadframe 12NC
/ Recipe waiting to be typed. Fill them in, click the save icon, and that
is when the row is written to TBLWIREBOND.

Nothing is written to the table for a machine that has no recipe yet, so
TBLWIREBOND never collects blank records. That is why Toad will not show
a row for machine 32233 until you save a recipe for it.

Machines with no recipe sort to the TOP whatever column you sort by, so a
machine you registered a minute ago is never buried on page 3.

A recipe whose machine is no longer registered in AWACSWSTYPE still
shows. Hiding rows the table really contains would be worse than showing
one whose parent has gone.
